Done-claims audit fixes (B6155-B6159). Golconda now raises the sheet's own Trait maximum to 10 (Attributes too), and a dot bought past the Generation's limit stays; the system fork keeps that maximum while Golconda lasts. A Cainite asleep for the day, Asleep, in torpor, Incapacitated or staked is refused in every WoDX Actions window a player opens (Common checks, Disciplines and the other power windows, Feed, Spend Blood, the Actions menu except Awaken by day and Torpor), and the api offers the same test and a no-action list for WoDX Combat. Registered conditions now reach the Any roll and Common checks: Drained and similar add their difficulty, Blurred sight and Blinded only on sight rolls; the power windows count every condition's difficulty, not only Drained's. In a fight a frenzy or Rötschreck check that holds the Beast off rolls again on the bearer's own turn once the turns it bought are spent, with the running total kept (V20 p. 297); outside a fight the rolls follow at once as before. The inner voice now hears a player's own sheet change. A clock change that lands while the night's clock work is still running gets one more run instead of being dropped. Destiny and Fate rerolls stay in the Any roll and Common checks windows; the note that promised them on every roll is corrected.
