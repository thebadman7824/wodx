## B6899: an audit says "everything" only when the coverage check passes

- Question: how does an audit show it left no script file out?
- Choice: tools/audit/coverage.mjs lists every module script and system file (git ls-files) and fails unless each has
  an item with a real verdict, named by its full path in `file` or `where`. A file named only by a bare file name, or
  only marked not-checked, stays open. Test: tools/harness/audit-coverage.test.mjs.
- Reverse: delete the tool and its test.
