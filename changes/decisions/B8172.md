## B8172. A head whose gates passed is not gated again when the pull request is marked ready (2026-11-26)
Repository workflow. pc-gates.yml runs on ready_for_review and title edits as well as pushes, and pr-gates.mjs only
looked for a passing wodx/gates status on the pull request's earlier commits (the commit list leaves the head out),
so marking a draft ready queued the full touched gates again on a head that had just passed them: PR 2637 (#2657
after #2655), PR 2660 (#2664 after #2661) and PR 2662 (#2668 after #2663) on 26 November. pr-gates.mjs now reads the
head's own statuses first and queues nothing when its wodx/gates is green. A run started by hand (workflow_dispatch)
still queues.

Reverse: drop the headPassed check in tools/pcq/pr-gates.mjs main().
