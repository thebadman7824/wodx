## B8020. Prose that matched a book is reworded (2026-11-25)
All modules, the system fork and docs. A full run of the 8-word overlap check (tools/books/books.mjs overlap, no cap, every published folder) found 5,280 shared runs: 696 distinct runs in 633 passages of 225 files. Each passage was read and sorted. 310 are game terms or lists (stat lines, Ability and trait lists, cost tables, book titles, power, path and place names), 13 match the owner's own Rothenstein scripts, and 107 are prose. The prose passages (123 places in 80 files) are now in WoDX's own words, with the mechanics, numbers and page references kept as the books give them; the Litany list in garou-deeds-rules.js is paraphrased. The full triage, with locations only, is in the project files (book-overlap/triage-2026-11-25.md). The runs themselves are never copied into the repository.

Reverse: revert the rewording commit.

## B8021. A shared run made only of game terms passes (2026-11-25)
Tools. tools/books/overlap-terms.json lists the single words of game terms (Attributes, Abilities, Backgrounds, Disciplines, Spheres, tribes, health levels and similar) found in the term passages of B8020, leaving out stop words and common English words. A shared run of 8 words passes when every word is a number or on that list, so stat lines and trait lists never fail.

Reverse: delete the words from overlap-terms.json; those runs then fail until allowlisted.

## B8022. Names and titles pass by hash (2026-11-25)
Tools. tools/books/overlap-allow.json keeps the SHA-256 (first 16 hex digits) of each shared run that a person checked and found to be a name, title or list but that B8021 does not cover (92 runs from the B8020 triage), with where it was first seen. No book words are kept, so the file cannot itself match a book. Books under ownBooks (rothenstein-scripts/, the owner's own writing) are not read. `overlap-gate.mjs --allow "<why>"` adds hashes after such a check.

Reverse: remove a hash; that run fails again.

## B8023. The overlap check is a gate (2026-11-25)
Tools. tools/books/overlap-gate.mjs runs the overlap check and fails on any run that is not a term (B8021) or allowlisted (B8022). It prints locations and hashes only; `--show` adds the words for the thread doing the rewrite. tools/quality-check.sh runs it on the files changed since origin/main wherever the book text is (cloud threads); GitHub's runners do not hold the books, so there it says skipped. A daily scheduled run (02:41 UTC) checks all of main against /mnt/project-files/book-text and sends failing locations to the coordinator. Harness: tools/harness/overlap-gate.test.mjs.

Reverse: take the Book overlap step out of tools/quality-check.sh and switch off the daily scheduled task.
