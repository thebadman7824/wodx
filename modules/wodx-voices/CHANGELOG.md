# wodx-voices changelog

Newest first. Add each new release at the top.

- 0.3.2 (spoken lines find a browser voice for 37 languages)
- 0.3.1 (2026-11-12): "Start a fresh cache" is now a real application class, so Foundry no longer logs an error at start. tools/voices/fetch_voices.py reads LibriTTS-R from its Parquet files on the Hugging Face hub (pyarrow) instead of the dataset viewer, which refused with 429; it waits as long as a server asks on 429 and uses HF_TOKEN when set.
- 0.3.0 (2026-11-12): The Chatterbox voice server on the Storyteller's PC (tools/voices/chatterbox_server.py) is the default engine, with Kokoro and then the browser's speech behind it. Human reference voices from LibriTTS-R (tools/voices/fetch_voices.py), chosen for lively, dialogue-like reading and spread apart. Each line's emotion and pace come from the line, the NPC's regard for the character, its wounds and a temper (flags.wodx-voices.temper). The server's address and key are this browser's own settings. Decisions B2112-B2116.
- 0.2.0 (2026-11-12): Only plot NPCs speak (Voiced (plot NPC) on the Actors list right-click menu), and only the lines written on their talk sheet; stock and generated lines stay text (B2111). Kokoro. The active Storyteller's browser renders each line once with Kokoro (offline, from Data/wodx-voices-engine, filled by tools/voices/fetch-engine.mjs), saves it to Data/wodx-voices-cache, and the people who see the line play the file, from the NPC's token when its scene is in view (fading with distance, muffled by walls). Each NPC's Kokoro voice is a steady blend of two voices of one accent. The browser's own speech is the fallback (no engine, a failed line, no Storyteller online, an NPC given another tongue). The Storyteller's improvised lines in character as an NPC can be read too, off by default (Improvement Desk vo1). An NPC can be given a tongue (cs, de, la) for the browser's speech. Settings: engine, device, Storyteller's lines, sound from the token, range, folders, cache warning, Start a fresh cache. Decisions B2106-B2111.
- 0.1.0 (2026-11-12): NPCs speak WoDX NPC talk cards aloud with the browser's own speech. A steady voice per NPC from its seed, known sex, age and speaking style; the Storyteller's choice in flags wins. Whispered lines are heard only by their recipients. World setting Voices (off by default), Storyteller hears every line; per-player volume and mute. Barks and cries stay silent. Decisions B2100-B2105.
