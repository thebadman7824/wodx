# Mage: The Dark Ages: creation totals

Book: WOD - Mage - The Dark Ages - Core Rulebook (Revised).pdf. It has no text layer, so this comes from WoDX's OCR (tools-env\text\batch2\damage). Page offset: printed = pdf − 1. Every ref below gives both.

The summary and the creation steps are on pdf 81–82 / printed 80–81.

## Attributes and Abilities
- Every Attribute starts at 1 dot. Physical, Social and Mental get 7 / 5 / 3 dots.
- Talents, Skills and Knowledges get 13 / 9 / 5 dots, with no Ability above 3.

## Magic
- Foundation starts at 1. Pillars get 3 dots.
- No Foundation or Pillar can start above 3.
- A Pillar may be higher than the Foundation, but casting past the Foundation carries its own costs (Chapter Four).
- Each Fellowship has its own Foundation and its own set of Pillars:

| Fellowship | Foundation | Pillars |
|---|---|---|
| Ahl-i-Batin | Al-Ikhlas (unity) | Al-Anbiya, Al-Fatihah, Al-Haj, Al-Layl and others |
| Messianic Voices | Divinity | the Archangels: Gavri-El, Mikha-El, Repha-El, Uri-El |
| Old Faith | Spontaneity | the Seasons: Autumn, Spring, Summer, Winter |
| Order of Hermes | Modus | the Forma, for example Anima and Vires; some names were lost in the OCR |
| Spirit-Talkers | Sensitivity | the Totems, for example Chieftain, Warrior, Wise One |
| Valdaermen | Sacrifice | the Runes, for example Fara, Forlog, Galdrar, Hjaldar |

The OCR broke up the Fellowship lines. The pairings above follow the order of the text, but check them against the page image before building anything on them.

## Backgrounds
- 5 dots.
- From Dark Ages: Vampire: Allies, Contacts, Influence, Mentor and Resources.
- New to this book: Chantry, Cray, Destiny, Familiar, Fount, Library, Sanctum, Servants and Talisman. (pdf 82 / printed 81)

## Willpower and Quintessence
- Willpower is 5. (pdf 82 / printed 81)
- Starting Quintessence is 5, or Cray + Fount if that is higher.
- The summary also mentions an Aura modifier, if any.

## Bonus points
- 15 bonus points. Flaws can add more if the Storyteller allows them. (pdf 82 / printed 81)

### Bonus point costs (pdf 82 / printed 81)

| Trait | Cost |
|---|---|
| Attribute | 5 per dot |
| Ability | 2 per dot |
| Ability Specialty | 1 each, up to 3 per Ability |
| Background | 1 per dot |
| Foundation | 5 per dot |
| Pillar | 3 per dot |
| Willpower | 1 per dot |
