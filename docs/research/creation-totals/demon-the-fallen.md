# Demon: The Fallen: creation totals

Book: WOD - Demon - The Fallen - Core Rulebook.pdf. This comes from WoDX's text dump (tools-env\text\batch3\demon; file names are pdf pages). Page offset: printed = pdf − 1. Every ref below gives both.

The summary is on pdf 124–125 / printed 123–124. The full steps are on pdf 127–129 / printed 126–128.

## Attributes and Abilities
- Every Attribute starts at 1 dot. Physical, Social and Mental get 7 / 5 / 3 dots.
- Talents, Skills and Knowledges get 13 / 9 / 5 dots, with no Ability above 3.

## Advantages
- Backgrounds: 5 dots. The list is Allies, Contacts, Eminence, Fame, Followers, Influence, Legacy, Mentor, Pacts, Paragon and Resources. (pdf 125 / printed 124)
- Lore: 3 dots. (pdf 124 / printed 123; pdf 127 / printed 126)
- Virtues: each starts at 1 dot, plus 3 more. The three Virtues are Conscience, Conviction and Courage. (pdf 128 / printed 127)

## Faith, Torment and Willpower
- Faith starts at 3. (pdf 128 / printed 127)
- Torment starts at a value set by House. (pdf 129 / printed 128; values in each House entry)
- Willpower = the two highest Virtues added together. (pdf 129 / printed 128)
