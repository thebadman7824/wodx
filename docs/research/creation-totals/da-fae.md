# Dark Ages: Fae: creation totals

Book: WOD - Vampire - The Dark Ages - Fae.pdf. This comes from WoDX's OCR (tools-env\text\batch2\dafae-ocr). Page offset: printed = pdf − 1. The page numbers on the OCR pages are hard to read; the offset fits the book's own "chart on p. 87" landing on pdf 88. Every ref below gives both.

The summary is on pdf 87–88 / printed 86–87.

## Attributes and Abilities
- Every Attribute starts at 1 dot. Physical, Social and Mental get 7 / 5 / 3 dots.
- Talents, Skills and Knowledges get 13 / 9 / 5 dots, with no Ability above 3. Bonus points can raise them past 3.
- Fae use the Dark Ages: Vampire Abilities, with three changes (pdf 91 / printed 90):
  - Kenning takes Empathy's place on the sheet. Empathy can still be taken.
  - Theology and Academics are left off the sheet, but can still be taken.

## Advantages
- Origin sets Birthright, Frailty, Mists, Weaving and Dominion dots:

| Origin | Mists | Weaving | Dominion dots |
|---|---|---|---|
| Changeling | 2 | 4 | 2 |
| Inanimae | 3 | 3 | 3 |
| Firstborn | 4 | 2 | 3 |

- Court sets the favored Dominion (pdf 88 / printed 87):

| Court | Favored Dominion |
|---|---|
| Spring | Dawn |
| Summer | Day |
| Autumn | Dusk |
| Winter | Night |
| Solstice | none |

- No Dominion above 3 at creation.
- Cantrips: each Weaving dot gives one cantrip in each Dominion the character has. Cantrips can only come from Dominions the character has. (pdf 87 / printed 86; worked example pdf 91 / printed 90)
- Backgrounds: 5 dots. (pdf 87–88 / printed 86–87)
  - From Dark Ages: Vampire: Allies, Contacts, Influence, Mentor, Resources and Status.
  - New to this book: Holdings, Library, Oaths, Retinue, Sprites and Treasures.
- Willpower is 4. (pdf 87 / printed 86; pdf 91 / printed 90)

## Echoes and Features
- Every character has one Echo. (pdf 91 / printed 90)
- Lesser Features: one per Mists dot, counting dots bought with bonus points. Inanimae also get one Greater Feature.
- Each extra Echo taken gives two Lesser Features or one Greater Feature.

## Bonus points
- 15 bonus points. Merits and Flaws are optional. (pdf 87 / printed 86)

### Bonus point costs (pdf 88 / printed 87)

| Trait | Cost |
|---|---|
| Attribute | 5 per dot |
| Ability | 2 per dot |
| Ability Specialty | 1 each, up to 3 per Ability |
| Background | 1 per dot |
| Dominion | 7 per dot |
| Willpower | 2 per dot |
| Weaving or Mists | 4 per dot |
